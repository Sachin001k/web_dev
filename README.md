# Web Development Learning Repository

This repository contains various web development projects and learning materials covering HTML, CSS, JavaScript, React, and TailWind CSS.

## 🚀 Quick Start with GitHub Codespaces

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/Sachin001k/web_dev)

Click the badge above or use the "Code" button → "Create codespace" to start developing in the cloud instantly!

## 📁 Repository Structure

- **Lecture Folders** (`Lecture_33`, `Lecture_39`, etc.): Individual lessons and exercises
- **React/**: React projects including `react-project-one` (Vite + React setup)
- **TailWind_CSS/**: TailWind CSS project with Vite
- **html_css_js/**: Basic HTML, CSS, and JavaScript projects
- **Mini_Project/**: Small web development projects
- **MiniProjectLeetCode/**: Coding challenges and solutions

## 🛠️ Development Environment

### Local Development
1. Clone the repository
2. Navigate to specific project folders
3. Install dependencies: `npm install` (for React/TailWind projects)
4. Start development server: `npm run dev` or use Live Server for static files

### GitHub Codespaces (Recommended)
- **Pre-configured environment** with Node.js, VS Code extensions, and development tools
- **Automatic port forwarding** for development servers
- **No setup required** - start coding immediately

## 🔧 Available Development Servers

- **Port 3000**: React development server
- **Port 5173**: Vite development server (React/TailWind)
- **Port 5505**: Live Server for static HTML/CSS/JS files
- **Port 8080**: General purpose development server
